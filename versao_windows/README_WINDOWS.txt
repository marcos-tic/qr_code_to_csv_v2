=======================================================
   EXTRATOR DE MINUTAS (PDF -> CSV) - VERSAO WINDOWS
=======================================================

Arquivo fonte desta versão: main_windows.py
Ícone usado pelo app: icone.png
Ilustração da aba Manual: csv_express_ilustracao.png
(O arquivo original main.py foi mantido intacto).

COMO USAR NO WINDOWS:

OPCAO 1: GERAR O EXECUTAVEL PORTATIL (.EXE) EM 1 CLIQUE
-------------------------------------------------------
1. Copie esta pasta "versao_windows" para o seu computador com Windows.
2. Certifique-se de ter o Python instalado (com a opcao "Add Python to PATH" marcada).
3. De dois cliques no arquivo:
      compilar_windows.bat

4. Ele instalara as bibliotecas e gerara automaticamente o:
      CSVExpress.exe

5. Apos isso, basta dar dois cliques no "CSVExpress.exe" para usar!
   Voce pode leva-lo para qualquer outro computador em um pendrive
   sem precisar de Python.


OPCAO 2: EXECUTAR DIRETO PELO PYTHON NO WINDOWS
-----------------------------------------------
1. Abra o prompt de comando nesta pasta.
2. Instale os requisitos:
      pip install -r requirements.txt
3. Execute:
      python main_windows.py
   ou de duplo clique em:
      executar_windows.bat
